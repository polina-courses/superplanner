# Близко — личный планировщик

Календарь, задачи и люди в одном приложении для Android. Сделано по мотивам Miracal, с правками:

- **Типы записей**: задача, событие, привычка, цель; дни рождения хранятся в «Людях». Кнопка «+» открывает меню выбора.
- **Привычки**: расписание, отметка «сделано», серия 🔥, процент за месяц, полоска последних 7 дней (по ней можно отмечать прошлые дни).
- **Цели**: дедлайн и прогресс шагами или числом («12 000 из 50 000 ₽», кнопка «+» добавляет сумму).
- **Свои категории** (Дом, Работа, Личное, Семья — переименовываются, удаляются, добавляются свои) и фильтр по ним в «Задачах».
- **Блок «Скоро»** на главном экране: дни рождения и события с отсчётом на 30 дней вперёд.
- **Повторяющиеся задачи и события**: каждый день, по будням, по выбранным дням недели, раз в N дней/недель/месяцев/лет, до определённой даты. Удалить можно один раз, «этот и следующие» или всю серию.
- **Без подписок и рекламы** и без слежки: данные хранятся только в памяти телефона. В интернет приложение ходит только за обновлениями собственного интерфейса.
- **Люди**: дни рождения (с возрастом или без года), «поддерживать связь раз в N», кнопка «Связались», история встреч.
- **Сегодня**: просроченное, план на день, дни рождения, кого пора набрать, завтра.
- **Календарь** месяц/неделя, **Задачи** по группам, **Обратный отсчёт**.
- Подпункты (для повторяющихся задач отметки сбрасываются каждый раз), важность «Низко / Средне / Обязательно», цвета и иконки.
- **Уведомления**: напоминания перед задачами и событиями, утренняя сводка дня, дни рождения, «пора связаться». Работают после перезагрузки телефона.
- Светлая и тёмная тема, резервная копия и восстановление.

## Как получить APK (без установки программ)

Сборку бесплатно сделает GitHub в облаке.

1. Зарегистрируйтесь на [github.com](https://github.com), если ещё нет аккаунта.
2. Нажмите **+ → New repository**. Имя — например, `blizko`. Выберите **Private**. Нажмите **Create repository**.
3. На странице репозитория нажмите **uploading an existing file**. Перетащите **содержимое** распакованной папки `blizko` (папки `app`, `gradle` и файлы `build.gradle`, `settings.gradle`, `gradle.properties`, `gradlew`, `gradlew.bat`, `README.md`). Нажмите **Commit changes**.
4. Скрытая папка `.github` при перетаскивании часто теряется, поэтому создайте файл сборки вручную: **Add file → Create new file**. В поле имени напишите ровно
   `.github/workflows/build.yml`,
   вставьте содержимое файла `build.yml` из папки `.github/workflows` (его же можно скопировать из раздела ниже) и нажмите **Commit changes**.
5. Откройте вкладку **Actions**. Сборка запустится сама и займёт 3–5 минут. Когда появится зелёная галочка, откройте её и внизу, в разделе **Artifacts**, скачайте **Blizko-APK** (это zip-архив с `Blizko.apk` внутри).
6. Перекиньте `Blizko.apk` на телефон, откройте его и разрешите «Установку из неизвестных источников» для приложения, через которое открываете (Файлы, Telegram и т. п.).

### Содержимое `.github/workflows/build.yml`

```yaml
name: Собрать APK

on:
  push:
  workflow_dispatch:

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-java@v4
        with:
          distribution: temurin
          java-version: '17'
      - uses: gradle/actions/setup-gradle@v4
      - name: Сборка
        run: |
          chmod +x gradlew
          ./gradlew assembleRelease --no-daemon
      - name: Переименовать
        run: cp app/build/outputs/apk/release/app-release.apk Blizko.apk
      - uses: actions/upload-artifact@v4
        with:
          name: Blizko-APK
          path: Blizko.apk
```

### Другой путь: Android Studio

Установите [Android Studio](https://developer.android.com/studio), выберите **Open** и откройте папку `blizko`, дождитесь синхронизации и нажмите **Build → Build App Bundle(s) / APK(s) → Build APK(s)**. Готовый файл появится в `app/build/outputs/apk/`.

## Первый запуск

- Разрешите уведомления, когда телефон спросит.
- В **Настройках** (шестерёнка) нажмите «Проверить уведомления → Через 5 сек».
- На Xiaomi, Huawei, Honor, Samsung и других телефонах с агрессивной экономией батареи: **Настройки телефона → Приложения → Близко → Батарея → Без ограничений** (на Xiaomi ещё **Автозапуск → вкл.**). Иначе система может «усыплять» напоминания.

## Резервная копия

**Настройки → Резервная копия → Сохранить** отправляет файл с данными куда удобно: в «Избранное» Telegram, на почту, в Google Диск. Восстановить можно там же: из файла или вставив текст. Если удалить приложение, данные удалятся вместе с ним, поэтому делайте копию время от времени.

## Обновление

**Обычные доработки (интерфейс, логика)** меняют только файл `app/src/main/assets/www/index.html`. Загрузите новый файл в эту папку на GitHub, и при следующем открытии приложение само скачает его и предложит «Обновить». Переустанавливать ничего не нужно. Проверить вручную можно в **Настройках → Интерфейс → Проверить**. GitHub отдаёт свежий файл с задержкой до 5 минут.

**Изменения «внутренностей»** (уведомления, иконка, хранение) требуют нового APK. Он всегда лежит по постоянной ссылке, сохраните её в закладки на телефоне:
https://github.com/polina-courses/superplanner/releases/latest/download/Blizko.apk
Та же ссылка есть в **Настройках → Скачать APK**. Новый APK ставится **поверх** старого, данные сохраняются: приложение подписано постоянным ключом `app/blizko.jks`. Не удаляйте и не меняйте этот файл.

Если скачанная версия интерфейса не запустится, через несколько секунд приложение само вернётся к встроенной.

## Важно знать

- Напоминания планируются на 60 дней вперёд и обновляются при каждом открытии приложения. Если не открывать его больше двух месяцев, напоминания закончатся, пока вы снова его не откроете.
- Репозиторий публичный, чтобы приложение могло скачивать обновления интерфейса без входа в GitHub. В нём только код, ваши данные хранятся на телефоне.

## Где что лежит

| Что | Файл |
|---|---|
| Весь интерфейс и логика | `app/src/main/assets/www/index.html` |
| Уведомления | `Scheduler.java`, `Notifier.java`, `AlarmReceiver.java`, `BootReceiver.java` |
| Хранение данных | `Store.java` (файл `data.json` во внутренней памяти) |
| Название и иконка | `res/values/strings.xml`, `res/drawable/ic_fg.xml` |

Интерфейс — обычная HTML-страница: её можно открыть в браузере на компьютере и посмотреть, как всё выглядит (уведомлений там не будет).
